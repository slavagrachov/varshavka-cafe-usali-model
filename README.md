## Работа с моделью

1. Изменяйте только input-ячейки листа `01_ВВОД`.
2. После изменений контролируйте лист `08_ПРОВЕРКИ`.
3. Любое изменение оформляйте через Issue, отдельную ветку и Pull Request.
4. Скрипт `scripts/s03_model_builder.py` воспроизводимо строит S03 v0.1.4 из утверждённого S02.
5. `scripts/releases/build_s03_v0_1_6_channels.mjs` воспроизводимо
   синхронизирует S03 v0.1.6 из утверждённой S03 v0.1.5.
6. `scripts/releases/build_s03_v0_1_7_breakfast.mjs` воспроизводимо
   формирует release candidate S03 v0.1.7 из утверждённой S03 v0.1.6.

## Ограничения

- НДС требует окончательного решения;
- часть OPEX требует документального подтверждения;
- средний чек ужина требует бизнес-подтверждения;
- инвестиционный раздел пока охватывает только посуду и барное стекло;
- полный бюджет инвестиций, Cash Flow и окупаемость не рассчитаны.
