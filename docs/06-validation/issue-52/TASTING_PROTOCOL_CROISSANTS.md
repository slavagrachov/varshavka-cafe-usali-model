# Сравнительный протокол образцов круассанов

Статус: **ШАБЛОН, ОБРАЗЦЫ НЕ ПОЛУЧЕНЫ**.

Каждый образец испытывается отдельной партией из 10 заготовок. Режим
поставщика фиксируется отдельно; образцы не выпекаются в искусственно
одинаковом режиме, если инструкции поставщиков различаются.
