# Issue №52 — единая матрица доказательств

Дата подготовки: 27 июля 2026 года.

## Назначение

Матрица устанавливает полный, взаимно непротиворечивый комплект доказательств
для закрытия Issue №52 и связанных записей `V-I-082`, `V-I-098`–`V-I-103`.
Получение коммерческих предложений, отправка RFQ и изменение расчётов в данный
этап не входят.

## Блокирующее расхождение овсяной каши

На листе `BREAKFAST_RECIPES` построчные значения готового выхода овсяной каши
составляют 45 + 111 + 88 + 4 + 4 + 1 = **253 г**, тогда как утверждённый
норматив равен **250 г**.

Расхождение не исправляется автоматически. До финального пересчёта необходимо:

1. определить, являются ли построчные значения аддитивными частями выхода;
2. документировать решение технолога;
3. при необходимости отдельно утвердить исправленную рецептуру;
4. добавить проверку равенства суммы компонентов нормативному выходу.

Пока решение отсутствует, контрольная проработка овсяной каши и финальный
пересчёт имеют статус `BLOCKED`.

### V-I-082

- документ на внутренний тариф 550 руб. с НДС;
- подтверждённые закупочные документы по всем используемым продуктам;

- слитый closure PR.

## Порядок обновления после получения доказательств

1. Сохранить первичные документы и протоколы в установленных папках.
2. Обновить PRICE_REGISTER.
3. Обновить BREAKFAST_RECIPES фактическими коэффициентами.
4. Выполнить формульный пересчёт BREAKFAST_COSTING.
5. Обновить `inputs/scenarios/S04_inputs.csv`.
6. Синхронизировать INPUT_REGISTER и input_dictionary.
7. Обновить ISSUE_REGISTER, не закрывая записи до проверки.
8. Пересобрать Excel S04.
9. Выполнить автоматические проверки.
10. Обновить SHA-256 и `inputs/model_manifest.json`.
11. Обновить документацию и Jupyter Book.
12. Создать и проверить отдельный closure PR.
13. После слияния закрыть связанные записи, затем Issue №52.
