# Контрольная проработка — сырная порция

Статус формы: **ШАБЛОН, ОЖИДАЕТ ОБРАЗЦОВ FONTINA DOP / FONTAL**.

Fontina DOP и каждый Fontal испытываются отдельными сериями и не признаются
взаимозаменяемыми до подписанного решения.

## Идентификация

| Поле | Значение |
|---|---|
| Чеддер: поставщик / артикул | |
| Тестируемый сыр: тип / поставщик / артикул | |
| Документы продукта | |
| Дата и серия | 1 серия на кандидат |
| Партия | 10 порций |
| Исполнитель / контролёр | |
| Оборудование | Нож/слайсер-кандидат, доска, холодильник, весы |

## Материальный баланс

| Сырьё | Брутто | Нетто/готовый выход | Факт отходов |
|---|---:|---:|---:|
| Чеддер | 200 г, 10 ломтиков | 200 г | |
| Fontina DOP или Fontal | 210 г | 200 г, 10 ломтиков | |
| **Порция** | **41 г расчётно** | **40 г; диапазон 38–42 г** | |

Зафиксировать время нарезки, температуру продукта, массу каждого ломтика,
форму обрези и пригодность остатка к дальнейшему использованию.

## Температурный шлюз

Пределы утверждены владельцем проекта 27.07.2026; режим хранения становится
окончательным после получения документа производителя. Классификация
приведена в [проекте раздела ППК](PPK_BREAKFAST_TEMPERATURE_CONTROL_DRAFT.md).

| Контрольная точка | Утверждённый критический предел | Документ-основание / раздел ППК | Фактический результат | PASS/FAIL |
|---|---|---|---|---|
| Хранение | По документу производителя; проектно 2–6 °C | Проект ППК; ОКТ / документ производителя | | |
| Нарезка | 4 ± 2 °C | Проект ППК; ТП | | |
| Подача | 8–14 °C, не позднее 30 минут | Проект ППК; ОКТ | | |

Органолептика проводится по [единому
правилу](ORGANOLEPTIC_ACCEPTANCE_RULE.md): вкус, аромат, текстура,
стабильность ломтика, холодная подача и плавление. Применяются утверждённые
пороги: индивидуально ≥ 3, средний балл каждого критерия ≥ 3,5, общий
средний ≥ 4,0; критические дефекты не допускаются.

- [ ] PASS — порции в диапазоне, потери подтверждены, температурный шлюз и
  органолептические критерии пройдены.
- [ ] FAIL — указать отклонение:

Подтверждения: карта нарезки, фотографии, протокол дегустации, расчёт стоимости
порции и подписи.
