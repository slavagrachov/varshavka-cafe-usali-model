## Органолептика

Применяется [единое правило](ORGANOLEPTIC_ACCEPTANCE_RULE.md). Минимальные
индивидуальный и средний баллы, а также перечень критических дефектов требуют
утверждения до испытания.

| Критерий | После охлаждения | 20 минут | 30 минут | 45 минут |
|---|---:|---:|---:|---:|
| Объём и форма, 1–5 | | | | |
| Корка, 1–5 | | | | |
| Слоистость и мякиш, 1–5 | | | | |
| Аромат сливочного масла, 1–5 | | | | |
| Посторонний вкус/жировой налёт | | | | |

- [ ] PASS — документы получены, 10 изделий соответствуют выходу, качество принято.
- [ ] FAIL — указать отклонение и необходимость повторной серии:

Подтверждения: документ поставщика, лист каждого изделия, режимы, фотографии
целого изделия и разреза, дегустационный лист и подписи.
