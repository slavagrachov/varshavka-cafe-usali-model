## Органолептика

Применяется [единое правило](ORGANOLEPTIC_ACCEPTANCE_RULE.md):
индивидуально ≥ 3, средний балл каждого критерия ≥ 3,5, общий средний ≥ 4,0;
критические дефекты не допускаются.
