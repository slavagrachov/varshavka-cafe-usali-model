# Issue №52 — проект автоматических проверок финального пересчёта

Статус: **ПРОЕКТ; В КОД И EXCEL НЕ ВНЕСЁН**.

Документ задаёт проверки, которые следует реализовать только после получения
первичных доказательств и отдельного разрешения на финальный пересчёт.

## Проверки источников цен

| Код | Условие `OK` |
|---|---|
| `CHK.BREAKFAST.PRICE_STATUS` | Все используемые цены имеют статус `подтверждено` |
| `CHK.BREAKFAST.PRICE_SOURCE` | Для каждой цены существует документ-основание и путь к нему |
| `CHK.BREAKFAST.VAT` | Ставка и сумма НДС заполнены и арифметически согласованы |
| `CHK.BREAKFAST.PRICE_UNIT` | Цена упаковки корректно преобразована в руб./кг, руб./л или руб./шт. |
| `CHK.BREAKFAST.PRICE_UNIQUE` | Идентификаторы цен уникальны, отсутствуют неоднозначные выбранные строки |

## Проверки рецептур

| Код | Условие `OK` |
|---|---|
| `CHK.BREAKFAST.RECIPE_BALANCE` | Брутто ≥ нетто; отходы и готовый выход образуют полный баланс |
| `CHK.BREAKFAST.OUTPUT_TOTAL` | Сумма готовых компонентов равна нормативному выходу блюда |
| `CHK.BREAKFAST.OATMEAL_250` | Утверждённый выход каши и сумма её компонентов равны 250 г |
| `CHK.BREAKFAST.NORMS` | Каждая норма BREAKFAST_COSTING формульно равна BREAKFAST_RECIPES |
| `CHK.BREAKFAST.NO_MANUAL_TOTALS` | Итоговые стоимости не содержат ручного ввода |

## Проверки структуры спроса и учёта

| Код | Условие `OK` |
|---|---|
| `CHK.BREAKFAST.SHARES` | 37,5% + 37,5% + 25% = 100% |
| `CHK.BREAKFAST.INACTIVE_ZERO` | Яйца Бенедикт и круассан с лососем имеют нулевой спрос |
| `CHK.BREAKFAST.COMMON_ONCE` | Круассан и сырная порция прибавлены один раз на комплекс |
| `CHK.BREAKFAST.DRINK_ONLY_HOTEL` | Напиток завтрака относится только к «Гостинице» |
| `CHK.BREAKFAST.NO_EXTERNAL_SALE` | Нет внешней продажи завтрака и доплаты |
| `CHK.BREAKFAST.ANNUAL_7300` | Годовая программа равна 7 300 оплачиваемых обслуживаний |
| `CHK.BREAKFAST.RESERVE` | База — 20 обслуживаний, производство — 22/21; резерв не повторяется в COGS |

## Ворота закрытия

Финальная валидация должна завершаться `FAIL`, если:

- используется хотя бы одна предварительная цена;
- отсутствует ставка НДС или документ-основание;
- не разрешено расхождение овсяной каши 253/250 г;
- отсутствует хотя бы один обязательный протокол;
- напиток 60 руб. не подтверждён рецептурой или утверждённым миксом;
- COGS, Hotel P&L или итог проекта не сходятся.
