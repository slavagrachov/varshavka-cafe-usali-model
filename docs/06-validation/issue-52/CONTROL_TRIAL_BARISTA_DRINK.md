# Контрольная проверка — напиток бариста гостиничного завтрака

Статус формы: **ШАБЛОН; BLOCKED СОСТАВОМ ИЛИ МИКСОМ НАПИТКОВ**.

До испытания необходимо утвердить, является ли единицей конкретный напиток
либо средневзвешенный выбор кофе и чая. Напиток имеет выход 200 мл, относится
только к направлению «Гостиница» и не формирует выручку «КОФЕ&ЧАЙ».

## Структура выбора и средневзвешенная стоимость

Структура выбора кофе и чая и допустимое отклонение от норматива 60 руб.
являются блокирующими исходными данными и не устанавливаются этой формой.

| Напиток | Утверждённая доля | Себестоимость единицы | Вклад: доля × себестоимость |
|---|---:|---:|---:|
| Кофе | Требует утверждения | | |
| Чай | Требует утверждения | | |
| Иной утверждённый вариант | Требует утверждения | | |
| **Итого** | **Должно быть 100%** | | |

единицы напитка)`.

## Температурный шлюз

Статус до утверждения ППК: **требует утверждения; серия не является закрывающим доказательством**.

|---|---|---|---|---|
| Температура приготовления | Требует утверждения | | | |
| Температура передачи гостю | Требует утверждения | | | |

Органолептика проводится по [единому
правилу](ORGANOLEPTIC_ACCEPTANCE_RULE.md): вкус, аромат, температура,
повторяемость и пригодность к одновременной выдаче. Минимальные
индивидуальный и средний баллы требуют утверждения до серии.

- [ ] PASS — структура выбора, допустимое отклонение, температурные и
  органолептические пороги утверждены; средневзвешенная стоимость находится в
  допуске; двойной учёт отсутствует.
- [ ] FAIL — указать отклонение:
- [ ] BLOCKED — хотя бы одно из перечисленных исходных решений не утверждено;
  серия не является закрывающим доказательством.

Подтверждения: технологические карты, журнал дозировок и выходов, калькуляция,
фотографии/выгрузка оборудования при наличии и подписи.
