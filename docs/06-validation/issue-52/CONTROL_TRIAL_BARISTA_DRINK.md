# Контрольная проверка — напиток бариста гостиничного завтрака

Статус формы: **ШАБЛОН; СТРУКТУРА И КРИТЕРИИ УТВЕРЖДЕНЫ, СЕРИИ НЕ
ПРОВЕДЕНЫ**.

Единица — средневзвешенный выбор американо и чёрного чая. Напиток имеет выход
200 мл, относится только к направлению «Гостиница» и не формирует выручку
«КОФЕ&ЧАЙ».

## Структура выбора и средневзвешенная стоимость

Структура и диапазон утверждены владельцем проекта 27.07.2026. После 100
фактических выборов структура пересматривается.

| Напиток | Утверждённая доля | Себестоимость единицы | Вклад: доля × себестоимость |
|---|---:|---:|---:|
| Американо 200 мл | 60% | | |

Органолептика проводится по [единому
правилу](ORGANOLEPTIC_ACCEPTANCE_RULE.md): вкус, аромат, температура,
повторяемость и пригодность к одновременной выдаче. Применяются утверждённые
пороги: индивидуально ≥ 3, средний балл каждого критерия ≥ 3,5, общий
средний ≥ 4,0; критические дефекты не допускаются.

- [ ] PASS — оформлены все три серии по 20 обслуживаний, доли дают 100%,
  средневзвешенная стоимость находится в диапазоне 57–63 руб.,
  температурный и органолептический шлюзы пройдены, двойной учёт отсутствует.
- [ ] FAIL — указать отклонение:
- [ ] BLOCKED — хотя бы одно из перечисленных исходных решений не утверждено;
  серия не является закрывающим доказательством.

Подтверждения: технологические карты, журнал дозировок и выходов, калькуляция,
фотографии/выгрузка оборудования при наличии и подписи.
