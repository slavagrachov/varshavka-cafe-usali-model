# Сравнительная дегустация Fontina DOP и Fontal

Статус: **ШАБЛОН, ОБРАЗЦЫ НЕ ПОЛУЧЕНЫ**.

Fontina DOP и Fontal оцениваются как разные продукты. Выбор Fontal как
HoReCa-аналога возможен только после испытания и не создаёт общего правила
взаимозаменяемости для иных артикулов.

Форма рассчитана минимум на шесть образцов. При большем числе кандидатов
добавляются строки и колонки с продолжением буквенных кодов.
