# Единое правило органолептической приёмки

Статус: **УТВЕРЖДЕНО ВЛАДЕЛЬЦЕМ ПРОЕКТА 27.07.2026; РЕЗУЛЬТАТЫ
ИСПЫТАНИЙ ЕЩЁ НЕ ПОЛУЧЕНЫ**.

Правило применяется к яичнице, омлету, овсяной каше, круассану, сырной
порции, напитку бариста и сравнительным дегустациям Issue №52.

## Обязательные условия

1. Каждый предусмотренный критерий оценивается по шкале от 1 до 5:
   - 1 — неприемлемо;
   - 2 — существенные недостатки;
   - 3 — приемлемо;
   - 4 — хорошо;
   - 5 — отлично.
2. Индивидуальная оценка каждого эксперта по каждому критерию — не ниже 3.
3. Средний балл каждого критерия — не ниже 3,5.
4. Общий средний балл по всем критериям — не ниже 4,0.
5. Критические дефекты не допускаются.
6. Результаты кандидатов считаются равными, если разница общего среднего
   балла составляет менее 0,10. В этом случае проводится повторная слепая
   серия; при повторном равенстве сначала сравниваются фактические потери,
   затем стоимость порции.

## Критические дефекты

Для всех объектов: признаки порчи, плесень, прогорклость, посторонний или
химический запах/вкус, инородное тело, загрязнение, несоответствие заявленному
составу или неучтённый аллерген.

Дополнительно:

- яичница — жидкий непрогретый белок, скорлупа, выраженное подгорание;
- омлет — жидкий непрогретый центр, расслоение, выраженное подгорание;
- каша — пригорание, кислый запах/вкус, жёсткие непроваренные хлопья;
- круассан — сырой липкий мякиш, прогорклый жир, непропечённые слои;
- сыр — нехарактерная плесень, слизь, аммиачный или прогорклый запах;
- напиток — посторонний запах воды, выраженный горелый вкус, неучтённый
  аллерген.

## Решение

- [ ] PASS — критические дефекты отсутствуют, каждая индивидуальная оценка
  не ниже 3, средний балл каждого критерия не ниже 3,5 и общий средний балл
  не ниже 4,0.
- [ ] FAIL — выявлен критический дефект или хотя бы один порог не выполнен.
- [ ] BLOCKED — форма заполнена не полностью, отсутствует идентификация
  образца/серии, температурный шлюз или подтверждающий документ.
