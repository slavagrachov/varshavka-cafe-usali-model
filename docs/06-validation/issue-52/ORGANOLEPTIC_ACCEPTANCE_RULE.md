# Единое правило органолептической приёмки

Статус: **ПРОЕКТ; ПОРОГИ ТРЕБУЮТ ОТДЕЛЬНОГО УТВЕРЖДЕНИЯ**.

Правило применяется к яичнице, омлету, овсяной каше, круассану, сырной
порции, напитку бариста и сравнительным дегустациям Issue №52.

## Обязательные условия

1. Каждый предусмотренный критерий оценивается по шкале от 1 до 5:
   - 1 — неприемлемо;
   - 2 — существенные недостатки;
   - 3 — приемлемо;
   - 4 — хорошо;
   - 5 — отлично.
2. Отсутствие критических дефектов является обязательным условием PASS.
3. Перечень критических дефектов устанавливается в форме конкретного
   испытания до начала серии.
4. Минимальный балл по каждому критерию и минимальный средний балл требуют
   отдельного утверждения до проведения испытания.
5. Пока пороги не утверждены, органолептический результат может быть
   зафиксирован, но итоговый PASS невозможен и серия не является закрывающим
   доказательством.

## Параметры утверждения до испытания

| Параметр | Утверждённое значение | Документ / решение | Дата | Ответственный |
|---|---|---|---|---|
| Минимальный балл по каждому критерию | Требует утверждения | | | |
| Минимальный средний балл | Требует утверждения | | | |
| Перечень критических дефектов | Требует утверждения | | | |
| Правило разрешения равного результата | Требует утверждения | | | |

## Решение

- [ ] PASS — пороги утверждены, критические дефекты отсутствуют, все
  индивидуальные и средний баллы соответствуют порогам.
- [ ] FAIL — выявлен критический дефект или хотя бы один порог не выполнен.
- [ ] BLOCKED — пороги не утверждены; серия не является закрывающим
  доказательством.
