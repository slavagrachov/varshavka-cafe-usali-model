# Проект раздела ППК — температурный контроль гостиничного завтрака

Статус: **ПРОЕКТ ДЛЯ ВКЛЮЧЕНИЯ В ППК; ПРЕДЕЛЫ УТВЕРЖДЕНЫ ВЛАДЕЛЬЦЕМ
ПРОЕКТА 27.07.2026, КЛАССИФИКАЦИЯ ПОДЛЕЖИТ ПРОВЕРКЕ В АНАЛИЗЕ ОПАСНОСТЕЙ**.

Документ не заменяет утверждённую ППК и санитарно-технологические документы.
До утверждения ППК контрольные серии подтверждают технологическую
повторяемость, но сами по себе не закрывают требования законодательства.

## Классификация

- **ККТ** — точка, для которой проектно предполагается критический предел
  безопасности; окончательный статус подтверждается анализом опасностей.
- **ОКТ** — операционная контрольная точка, обеспечивающая безопасное
  хранение, обращение или выдачу.
- **ТП** — технологический параметр качества и повторяемости.

## Регистрация и корректирующие действия

Для каждой точки фиксируются дата, время, серия, изделие, прибор и его
калибровка, фактическое значение, исполнитель и контролёр. При FAIL продукт
не признаётся закрывающим образцом; оформляется корректирующее действие и
повторная серия. Для ККТ (проект) продукт из непрошедшей контрольной единицы
к выдаче не допускается до решения ответственного за ППК.

Инструкция выбранного поставщика круассана имеет приоритет над стартовыми
режимами. Режим хранения сыра становится окончательным только после получения
документа производителя.
