# Инвестиционный пакет VARSHAVKA v3.0.0

Раздел содержит утверждённую структуру инвестиционного контура S04 без
закупочных цен и без расчёта IRR, NPV и срока окупаемости.

## Единый источник данных

Сквозной ключ пакета — `INV_CODE`.

CSV-файлы являются машинно-читаемыми приложениями. Файл
`INVESTMENT_PACKAGE_TEMPLATES_v3.0.0.xlsx` объединяет те же приложения в
редактируемой книге и добавляет формулы для:

- полной стоимости запуска предложения;
- потребности в запасе и округления до закупочных упаковок;
- 13-недельного Cash Flow;
- контроля обязательных ценовых и технических шлюзов.

Итоги не должны повторно вводиться вручную.

## Правила использования

1. Условные и исключённые позиции имеют нулевое количество базового
   сценария.
2. Условная позиция переводится в закупку только после подписанного
   доказательства, указанного в `CONDITIONAL_EQUIPMENT_GATES`.
3. Поля актуальных цен остаются пустыми, а статус — `NOT_REQUESTED`.
4. Исторические 254 437 руб. посуды зала и 117 576 руб. барного стекла
   сохранены только как оценки, не прошедшие повторную проверку S04.
5. Размеры оборудования являются коридорами планировки. Паспорт модели
   имеет приоритет.
6. Запросы поставщикам в рамках подготовки пакета не отправлялись.
7. Excel S04 и его экономические результаты пакетом не изменяются.

## Проверка

```bash
python scripts/validate_investment_register.py
```

Проверка контролирует уникальность кодов, классификацию, нулевую базу
условных и исключённых позиций, наличие шлюзов, структуру двух 13-недельных
контуров, отсутствие актуальных закупочных цен и целостность XLSX.
