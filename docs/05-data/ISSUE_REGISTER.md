# Единый реестр вопросов и контрольных действий VARSHAVKA

Дата среза: 26 июля 2026 года.

## Назначение и статус реестра

Этот файл является единым полным реестром решений, незакрытых исходных
данных, рисков, испытаний и корректирующих действий проекта VARSHAVKA.

До создания этого документа в репозитории существовали:

- GitHub Issues для отдельных изменений финансовой модели и сайта;
- `OPEN_QUESTIONS.md` с восемью вопросами ранней версии модели;
- `INPUT_REGISTER.md` с параметрами базовой версии;
- ADR и протоколы проверок.

Ни один из этих источников отдельно не охватывал все вопросы разработки
МЕНЮ КУХНИ, производственной программы, оборудования и БАНКЕТОВ. В исходном
состоянии до формирования этого реестра открытых GitHub Issues не было;
затем созданы тематические Issues #36–#53. Ранний список открытых вопросов
частично устарел: например, питание сотрудников уже разработано, а наличная
модель БАНКЕТОВ в реестре inputs ещё не отражена.

## Правила контроля

1. Каждой записи присваивается постоянный код `V-I-xxx`.
2. Этот реестр содержит все записи, включая закрытые, заменённые и
   контролируемые после запуска.
3. Исполнимые пакеты работ отражаются отдельными GitHub Issues. Детальные
   записи могут ссылаться на одну тематическую карточку.
4. Статусы:
   - `OPEN` — требуется решение или работа;
   - `BLOCKED` — выполнение невозможно без внешних данных;
   - `PLANNED` — способ выполнения и контрольное событие определены;
   - `MONITOR` — решение принято, требуется фактическая проверка;
   - `CLOSED` — критерий выполнен и имеется подтверждение;
   - `SUPERSEDED` — правило заменено последующим решением.
5. Issue закрывается только при наличии ссылки на проверяемый результат:
   протокол, технологическую карту, расчёт, паспорт оборудования, PR или
   утверждённое решение.
6. Изменение рецептуры, финансовой методики или производственного правила
   после утверждения оформляется отдельным решением и при необходимости ADR.
7. Реестр проверяется не реже одного раза в неделю до запуска и ежемесячно
   после запуска.
