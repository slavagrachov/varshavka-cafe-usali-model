# Issue #80 — комплект меню, калькуляций и технологических карт

Файл `VARSHAVKA_MENU_COSTING_TECH_CARDS_DRAFT_v1.0.0.xlsx` предназначен для построчного согласования с шеф-поваром.

## Состав

- 31 активная позиция `VKM-001`…`VKM-031`;
- 31 калькуляционная карта `VKC-001`…`VKC-031`;
- 31 технологическая карта `VKT-001`…`VKT-031`;
- три детальные карты гостиничного завтрака со статусом `DRAFT` по S04;
- 28 видимых карт-скелетов со статусом `BLOCKED`;
- реестры сырья и цен, аллергенов и безопасности, вопросов шеф-повару, согласования, проверок и источников.

Две архивные рецептуры со статусом `SUPERSEDED` приведены только в паспорте и реестре источников и не входят в активное меню.

## Ограничения

Комплект не является окончательно утверждённой рецептурной, технологической или санитарной документацией. Не заполненные параметры оставлены пустыми и обозначены `BLOCKED`; нулевые значения вместо отсутствующих данных не подставлялись. Закупочные наблюдения завтрака остаются `DRAFT`, а цена Fontina/Fontal — `ASSUMPTION` до получения документов поставщиков и решения после дегустации.
