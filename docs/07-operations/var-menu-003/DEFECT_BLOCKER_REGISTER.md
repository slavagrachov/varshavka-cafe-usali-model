# Defect / Blocker Register — Issue #92

## Публикационные дефекты

- S1: 0.
- S2: 0.
- `PUB-003-001 / S3 / NON-BLOCKING`: исправленный бинарный XLSX v1.0.1 не опубликован в ветке из-за ограничения текущего GitHub API-коннектора на безопасную передачу локального бинарного файла одним вызовом.

Попытка прямой загрузки была отклонена exact-byte проверкой: Git blob SHA опубликованного объекта не совпал с локальным Git blob SHA. Повреждённый объект удалён из ветки.

## Исправленный дефект XLSX

- `XLSX-003-001 / S2`: пересекающиеся merged ranges `A44:J44` и `F44:J44`.
- Исправление: диапазоны заменены на `A44:D44` и `F44:J44`.
- Результат локальной проверки: `MERGED_RANGE_CONFLICTS = 0`.
- Исправленная версия: `v1.0.1`.
- Ожидаемый SHA-256: `c550ba53962dea5a1e1f341fa200ae3eacefda07e1a5b71a07688951f5687de5`.

## Safety blockers

`FS-003-01…FS-003-15` остаются OPEN. Они полностью отражены в локальном XLSX и документации пакета.
