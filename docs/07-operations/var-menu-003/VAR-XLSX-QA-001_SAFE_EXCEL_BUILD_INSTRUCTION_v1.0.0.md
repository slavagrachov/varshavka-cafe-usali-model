# VAR-XLSX-QA-001 — обязательная инструкция безопасной сборки Excel

Версия: 1.0.0  
Дата: 2026-08-04  
Область: все XLSX-пакеты VARSHAVKA.

## 1. Главное правило объединения ячеек

Перед экспортом XLSX необходимо сформировать полный реестр merged ranges по каждому листу.

Запрещены пересекающиеся, вложенные, повторные объединения и изменение части объединённого диапазона без предварительного `unmerge`.

## 2. Обязательная проверка перед выдачей

После экспорта необходимо:

1. открыть XLSX как ZIP;
2. извлечь все `<mergeCell ref="...">` из `xl/worksheets/sheet*.xml`;
3. попарно проверить пересечения;
4. не выпускать файл при наличии конфликта;
5. повторно импортировать XLSX;
6. проверить число и названия листов;
7. просканировать формулы на ошибки;
8. выполнить визуальный render;
9. рассчитать SHA-256 только после успешного QA.

## 3. Критерий выпуска

- `MERGED_RANGE_CONFLICTS = 0`;
- `FORMULA_ERRORS = 0`;
- round-trip import successful;
- sheet count correct;
- visual review passed;
- SHA-256 calculated for final version.

Ошибка пересекающихся merged ranges классифицируется как `S2 / BLOCKING_XLSX_COMPATIBILITY_DEFECT`.
