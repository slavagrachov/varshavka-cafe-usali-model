# WAVE 0 — Рамка MAKE / BUY / HYBRID

## MAKE
Известно: собственное производство рассматривается как допустимая модель. Параметры VKM-005 не переносятся.
Неизвестно: рецепт, выход, труд, энергия, мощность, стабильность.
Критерии: полная переменная стоимость, качество, гибкость, загрузка, потери.
Риски: нестабильность партии, недостаток мощности, технологическая сложность.

## BUY
Известно: возможна закупка готового, замороженного или частично выпеченного изделия.
Неизвестно: поставщики, спецификация, минимальная партия, цена, логистика, порядок подготовки к реализации.
Критерии: закупочная и полная стоимость, стабильность, срок хранения, доступность.
Риски: зависимость от поставщика, несоответствие профиля, списания.

## HYBRID
Известно: возможно сочетание основного MAKE и резервного BUY.
Неизвестно: доля резерва, правила переключения, объём страхового запаса.
Критерии: непрерывность, стоимость резерва, сложность запасов.
Риски: двойная номенклатура и различия органолептики.

Окончательная модель на Wave 0 не выбрана.
