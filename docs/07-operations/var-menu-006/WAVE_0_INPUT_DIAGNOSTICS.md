# WAVE 0 — Диагностика входов

## 1. Связь с VKM-005

| Категория | Что относится | Правило применения |
|---|---|---|
| Структурно применимое | паспорт, Wave/Owner Gates, MAKE/BUY/HYBRID, три листа будущего XLSX, журналы, QA и IV | использовать как форму организации |
| Условно применимое | тип оборудования, базовая последовательность хлебного производства, упаковочная логика, подход к каналам | проверять для томатного состава и фактической площадки |
| Не переносимое без новой верификации | рецептура, biga, гидратация, массы, выход, потери, ферментация, выпечка, хранение, COGS, цена, аллергены и safety | рассматривать как неподтверждённые данные |

## 2. Предварительные концепции

| Концепция | Продуктовая роль | Преимущества | Основные риски | Ожидаемое влияние | Статус |
|---|---|---|---|---|---|
| Томатная паста | равномерный вкус и цвет | доступность, понятный профиль | дополнительная вода и кислотность; вариабельность концентрации | гидратация и ферментация требуют перерасчёта | `EXPERT_ASSUMPTION_PENDING_CHEF_MANAGER_VERIFICATION` |
| Томатный порошок | концентрированный вкус/цвет без прямого добавления жидкой фазы | дозируемость, хранение | связывание воды; возможное снижение расширения теста; рост стоимости | более выраженный цвет, изменение структуры и влажности | `EXPERT_ASSUMPTION_PENDING_CHEF_MANAGER_VERIFICATION` |
| Вяленые томаты | премиальные видимые включения | текстура и выраженный вкус | масло/соль/влага включений, неоднородность, локальные разрывы мякиша | влияние на формование, порционирование и хранение | `EXPERT_ASSUMPTION_PENDING_CHEF_MANAGER_VERIFICATION` |
| Комбинированная | базовый цвет + видимые включения | наиболее выраженная идентичность | максимальная сложность и себестоимость | требуется отдельная технологическая проработка | `EXPERT_ASSUMPTION_PENDING_CHEF_MANAGER_VERIFICATION` |

## 3. Подтверждённые данные

- Коды и название позиции.
- Scope только VKM-006/VKC-006/VKT-006.
- Требование статуса не выше `PENDING_CHEF_MANAGER_VERIFICATION`.
- VKM-005 используется только как проверяемый структурный источник.

## 4. Отсутствующие данные

- проектный выход и допустимое отклонение массы;
- назначение и каналы;
- желаемая органолептика;
- допустимые томатные ингредиенты;
- ограничения по оборудованию;
- поставщики и закупочные спецификации;
- прогноз спроса и критерии экономики;
- подтверждённые safety-параметры.

## 5. Экспертные гипотезы

- Томатный ингредиент может изменить водопоглощение, кислотность, газоудержание, цвет и срок хранения.
- Порошок потенциально удобнее для стандартизации, паста — для доступности, вяленые томаты — для премиального позиционирования.
- Все гипотезы требуют лабораторной/кухонной контрольной проработки.
