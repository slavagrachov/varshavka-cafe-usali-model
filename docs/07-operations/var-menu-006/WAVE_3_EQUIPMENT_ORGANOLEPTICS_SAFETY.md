# WAVE 3 — Оборудование, органолептика и безопасность

Статус позиции: `SAFETY_BLOCKED_PENDING_VALIDATION`.

## 1. Оборудование и инвентарь

Базовый комплект сохраняется от VKM-005 и требует фактической сверки на площадке:

- весы для сырья;
- точные весы для дрожжей и томатного порошка;
- тестомес;
- ёмкости для biga и основной ферментации;
- термометр;
- скребки;
- производственные столы;
- доски или противни для расстойки;
- ткань/лён или иной разделительный материал;
- печь с возможностью подачи пара либо утверждённой альтернативой;
- решётки для охлаждения;
- маркированная тара для хранения томатного компонента.

Дополнительно для V1:

- мелкое сито;
- сухая герметичная тара;
- защита порошка от влаги.

Дополнительно для V2:

- мерная/весовая тара для пасты;
- чистая лопатка;
- закрываемая маркированная ёмкость для открытой упаковки;
- холодильное хранение, если это установлено маркировкой конкретного продукта.

## 2. Производственная загрузка

- Новый отдельный тип оборудования предварительно не требуется.
- V1 добавляет операцию просеивания/диспергирования порошка.
- V2 добавляет вскрытие упаковки, дозирование, диспергирование, маркировку остатка и санитарную обработку тары.
- Фактическое дополнительное время труда имеет статус `UNKNOWN_NOT_ZERO`.
- V2 потенциально сложнее по управлению остатками и списаниям.

## 3. Проектная органолептическая спецификация

| Показатель | Целевой результат | Брак/отклонение |
|---|---|---|
| Внешний вид | порционная чиабатта, форма близка к VKM-005 | расплывшаяся, сильно деформированная |
| Корка | тонкая или умеренно хрустящая, равномерная | подгоревшая, чрезмерно толстая |
| Цвет корки | золотисто-красноватый без почернения | серый, буро-чёрный, пятнистый |
| Цвет мякиша | однородный светло-красный/оранжевый | непромесы, белые или тёмные полосы |
| Пористость | выраженная неравномерная пористость чиабатты | плотный мелкопористый или сырой мякиш |
| Аромат | хлебный с чистым томатным оттенком | затхлый, горелый, химический |
| Вкус | сбалансированный хлебно-томатный | чрезмерно кислый, горький, солёный |
| Текстура | эластичный влажный мякиш без липкости | клейкий, резинистый, крошащийся |
| Масса | 100 г после охлаждения, допуск устанавливает шеф | выход вне подтверждённого допуска |

## 4. Аллергены и cross-contact

- Базовый обязательный аллерген: глютен пшеницы.
- Томат сам по себе не входит в стандартный перечень основных обязательных аллергенов, но состав конкретного порошка или пасты должен быть проверен.
- Порошок может содержать антислеживающий агент и следовые аллергены производства; требуется спецификация/COA.
- Паста может содержать соль, сахар, регуляторы кислотности или иные добавки; требуется этикетка и спецификация.
- Использовать отдельную чистую тару и инвентарь либо документированную мойку между продуктами.

## 5. Safety-блокеры

| ID | Блокер | Условие снятия |
|---|---|---|
| FS-106-01 | Нет утверждённой спецификации томатного порошка | паспорт/COA, состав, аллергены, срок и хранение |
| FS-106-02 | Нет утверждённой спецификации пасты | этикетка/спецификация, Brix, состав, хранение после открытия |
| FS-106-03 | Не подтверждены фактические режимы ферментации и выпечки | минимум три воспроизводимых прогона выбранного варианта |
| FS-106-04 | Не подтверждена температура центра и готовность | измерения контрольных прогонов |
| FS-106-05 | Не подтверждён срок хранения | тесты 2/24/48 часов и решение шефа |
| FS-106-06 | Не установлен допуск массы 100 г | решение шеф-повара |
| FS-106-07 | Не проверена уборка порошковой пыли и остатков пасты | санитарная проверка на площадке |

До снятия критических блокеров не присваивать `READY_FOR_PRODUCTION`.
