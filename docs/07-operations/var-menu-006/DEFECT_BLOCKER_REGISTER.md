# Defect / Blocker Register — Wave 0

| ID | Тип | Описание | Серьёзность | Статус | Условие снятия |
|---|---|---|---|---|---|
| B-001 | INPUT | Не подтверждён проектный выход | S1 | OPEN | решение владельца |
| B-002 | INPUT | Не подтверждены назначение и каналы | S1 | OPEN | решение владельца |
| B-003 | CONCEPT | Не выбрана концепция для Wave 1 | S1 | OPEN | Owner Gate 0 |
| B-004 | MAKE_BUY | Не определён дальнейший состав MAKE/BUY/HYBRID | S2 | OPEN | Owner Gate 0 |
| B-005 | CHEF | Нет подтверждённой органолептической спецификации | S2 | OPEN | ответ шеф-повара |
| B-006 | MANAGEMENT | Нет прогноза спроса и закупочных данных | S2 | OPEN | ответ управляющего |
| B-007 | SAFETY | Safety-параметры томатного состава не определены | S1 | OPEN | Wave 3 и контрольная проработка |

Открытые блокеры не препятствуют Owner Gate 0, но ограничивают переход к соответствующим последующим расчётам.
