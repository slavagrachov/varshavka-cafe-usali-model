## Правила использования

1. Перед отправкой указать юридическое лицо, ИНН, точный адрес доставки,
   контактное лицо, телефон, e-mail и плановую месячную потребность.
2. Не принимать публичную цену интернет-магазина за коммерческое предложение.
3. Полученный ответ сохранить в `sources/procurement/breakfast/YYYY-MM-DD_<vendor>`,
   зарегистрировать в `PRICE_REGISTER` и связать с Issue #39 и #52.
4. Fontina DOP и Fontal учитывать раздельно. Fontal допускается к сравнению
   только как HoReCa-аналог и не заменяет Fontina DOP до контрольной дегустации.
5. Запросы из этой папки не являются заказом или акцептом оферты.
