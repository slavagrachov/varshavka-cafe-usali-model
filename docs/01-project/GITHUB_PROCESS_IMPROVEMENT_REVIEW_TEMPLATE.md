## 6. Ручные действия владельца

Для каждого действия указать:

- было ли оно действительно необходимо;
- мог ли ChatGPT или информационная система выполнить его автоматически;
- должен ли владелец помнить это действие;
- как сократить действие до одной команды или одного решения.
