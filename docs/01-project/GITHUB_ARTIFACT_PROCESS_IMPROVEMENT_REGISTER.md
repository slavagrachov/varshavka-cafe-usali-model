# Реестр непрерывных улучшений процесса GitHub

## 1. Назначение

Реестр хранит выявленные отклонения, причины, решения владельца и результаты проверки эффективности улучшений жизненного цикла GitHub.

## 2. Статусы

`PROPOSED` → `OWNER_ACCEPTED` / `OWNER_REJECTED` / `DEFERRED` → `IMPLEMENTED` → `VERIFIED`.

Изменение регламента или программ без зарегистрированной записи и отдельной Issue запрещено, кроме немедленного исправления критического блокирующего дефекта. Такое исправление регистрируется ретроспективно.

## 4. Правило использования

После каждой полной или частичной итерации ChatGPT обновляет этот реестр. Владелец принимает одно из решений: принять, отклонить, отложить или изменить приоритет. Эффективность принятого улучшения обязательно проверяется в следующей подходящей итерации.
