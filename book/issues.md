# Контроль незакрытых данных

## Назначение реестра

`ISSUE_REGISTER` содержит 136 постоянных записей по меню, сырью,
безопасности, спросу, персоналу, оборудованию, праву, финансам и
инвестициям. Закрытие тематической GitHub Issue не превращает автоматически
неполученный документ или непроведённое испытание в подтверждённый факт.

[Открыть полный ISSUE_REGISTER](https://github.com/slavagrachov/varshavka-cafe-usali-model/blob/main/docs/05-data/ISSUE_REGISTER.md).

## Критические контуры

| Контур | Основной незакрытый результат |
|---|---|
| Безопасность | сроки реализации, ХАССП, ППК, температурные режимы |
| Сырьё | выход сельди, рыбы, мяса, сыров и маринадов |
| Персонал | вечерний пик, ранняя выпечка, экспедиция и дефицит мойки |
| Инженерия | технические условия на мощность, вентиляцию, воду и канализацию |
| Оборудование | паспорта моделей, планировка и совмещённый стресс-тест |
| БАНКЕТЫ | контрольное мероприятие, cook–chill, переменный труд |
| Право | единый оператор, помещения, ККТ, алкоголь и трудовые отношения |
| Инвестиции | CAPEX, оборотный капитал, Cash Flow, IRR и NPV |
| Финансы | НДС и рецептурная себестоимость полного меню |

## Исходные данные инвестиционного контура

В реестр добавлены 33 самостоятельные задачи `V-I-104–V-I-136`,
соответствующие документам `DOC-INV-001–DOC-INV-033`.

| Группа | Требуемые результаты |
|---|---|
| Планировка и строительство | актуальная планировка; вместимость 20/26 мест; дефектная ведомость; ведомость объёмов работ; имущество арендодателя |
| Инженерия | ТУ электроснабжения; стоимость 100/125/150 кВт; вентиляция; вода и канализация; жироуловитель |
| Оборудование и испытания | паспорта оборудования; контрольный банкет; хронометраж холодного участка; тест 25 кассет/час |
| Сервировка и бар | матрица сервировки S04; банкетная сервировка; программа бара; карта напитков |
| Закупки и расчёты | размеры упаковок; MOQ и сроки поставок; оплата Гостиницей; агрегаторы; банкетный аванс |
| Право и финансирование | аренда и депозит; НДС; капитализация; получатель и источник инвестиций; возврат средств; минимальный денежный остаток |
| Календарь и коды | график CAPEX-платежей; график запуска; первоисточник BAN-01–BAN-07 |

Каждая задача имеет ответственного, приоритет, документ-основание и
проверяемый критерий закрытия. Полный состав опубликован в
[ISSUE_REGISTER](https://github.com/slavagrachov/varshavka-cafe-usali-model/blob/main/docs/05-data/ISSUE_REGISTER.md)
и [реестре недостающих инвестиционных документов](https://github.com/slavagrachov/varshavka-cafe-usali-model/blob/main/docs/10-investment/MISSING_INVESTMENT_DOCUMENTS_REGISTER.csv).

## Issue №52

Issue №52 закрыта решением владельца 28 июля 2026 года. Выполнены
структурная синхронизация Гостиницы и КОФЕ&ЧАЙ, прозрачная калькуляция
завтрака, внутренние критерии и публикация полевого пакета.

Документы поставщиков и фактические контрольные серии не получены и
остаются самостоятельными задачами закупочного и операционного контуров.
Такое разграничение позволяет завершить релиз без искажения качества
исходных данных.

## Управленческое правило

Для каждого показателя на сайте следует различать:

1. утверждённое решение;
2. расчётное значение;
3. предварительное допущение;
4. подтверждённый документом факт;
5. проверенный физическим испытанием результат.

На договоры и закупки можно опираться только после достижения требуемого
уровня подтверждения.
