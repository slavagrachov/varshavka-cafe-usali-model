## Ограничения

- паспортные мощности выбранных моделей оборудования пока не получены;
- значения единичной мощности в энергетическом реестре являются
  предварительными инженерными оценками;
- установленная мощность базового электрического контура Кухни составляет
  94,23 кВт, пиковая одновременная — 72,00 кВт;
- бар, вентиляция, кондиционирование, освещение и общеобъектовые системы в
  эти итоги не включены;
- мощности хлебного и кондитерского участков требуют подтверждения
  контрольной выпечкой и хронометражем;
- пятничный вечерний пик остаётся кадровым ограничением: фактически
  доступен один производственный специалист при потребности не менее трёх.

Контрольные хеш-суммы находятся в `SHA256SUMS.txt`.
